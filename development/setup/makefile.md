# Makefile

The Makefile provides short commands for common development tasks.

| Command | Purpose |
|---|---|
| `make install` | Install dependencies and Git hooks |
| `make format` | Fix and format code |
| `make lint` | Check code quality |
| `make typecheck` | Run mypy |
| `make test` | Run tests and coverage |
| `make check` | Run lint, type checking and tests |
| `make notebook` | Open the API exploration notebook |
| `make clean` | Remove generated files |

The goal is to make development commands consistent and easy to remember.
